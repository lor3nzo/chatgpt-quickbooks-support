# ChatGPT QuickBooks Support

Turn ChatGPT into a focused QuickBooks Online support assistant for bookkeeping and automation.

This repo contains a versioned prompt + configuration pack you can install into a **ChatGPT project** with project-only memory. Once installed, your team gets a reusable workspace that:

- Specializes in QuickBooks Online bookkeeping, configuration, and automation :contentReference[oaicite:1]{index=1}  
- Helps troubleshoot issues, design workflows, and improve reporting  
- Follows Lean and first-principles thinking for clear, practical guidance :contentReference[oaicite:2]{index=2}  

Quick start:

1. Create a new ChatGPT project (project-only memory) :contentReference[oaicite:3]{index=3}  
2. Upload the `.md` files from the latest release (`INDEX_QuickBooks_Premium_Support_...`) :contentReference[oaicite:4]{index=4}  
3. In a new chat inside that project, type `GO` to activate QuickBooks Premium Support :contentReference[oaicite:5]{index=5}
