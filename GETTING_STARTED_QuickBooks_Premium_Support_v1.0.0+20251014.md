# GETTING_STARTED — QuickBooks Premium Support

## Metadata
Version: v1.0.0+20251014

### Steps
1. Create a **new Project** with **project-only memory**.
2. Paste the **PROMPT file** into General Chat and complete setup.
3. Generate all configuration files (done).
4. Upload all files to the Project’s **file section**.
5. Delete the setup chat.
6. Validate installation (see VALIDATE_INSTALL file).
7. Activate by typing `GO`.
8. Optionally, upload data files following the DATA_README.
