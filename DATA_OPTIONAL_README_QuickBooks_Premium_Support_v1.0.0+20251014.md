# DATA_OPTIONAL_README — QuickBooks Premium Support

## Metadata
Version: v1.0.0+20251014

## Purpose
Guides users on how to upload data files (e.g., exported QBO data, CSV/Excel templates) for expert analysis and troubleshooting.

## Accepted Formats
- CSV
- Excel (.xlsx)
- QBO exports (.zip or .xlsx)
- JSON (for automation configs)

## Naming Convention
`DATA_{TYPE}_{DESCRIPTION}_vYYYYMMDD`

## Upload Instructions
1. Export data from QBO or prepare the required template.
2. Name the file according to the naming convention.
3. Upload the file into the project file section.

## Validation Step
After upload, type: `import data`  
The expert will confirm file recognition and readiness.

## Maintenance Notes
Version your data files as you update them. Keep only the latest valid file unless historical versions are required.
